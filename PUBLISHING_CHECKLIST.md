# Publication Status

The prepared release has fresh Git history and an explicit file list. The local research repository and its history are preserved separately.

Before publication:

- Review `data/processed/release_validation_report.md`.
- Confirm author metadata and data licensing rights.
- Confirm consent and institutional study terms permit public aggregate sharing.
- Inspect `git ls-tree -r --name-only HEAD` and `git log --oneline`.
- Obtain the study owner's authorization to push.

The destination is https://github.com/Anteater10/Scitrek-immersive-document-pilot.git.
Do not use `git add .` in the original research repository as a publication workflow.
